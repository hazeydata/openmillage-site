# OpenMillage site
Static GitHub Pages site built by `python3 build.py` from ../ptax/data into docs/. Serve docs/ via Pages (branch main, /docs).

## Ballot measure 3 baseline page (OM-FL-AMEND3-BASELINE-001)
`python3 amend3.py` (run after `build.py`) writes the page at the slug in `amend3_config.json` (one value; it is currently `fl/amendment-3`), a CSV/JSON of exactly the rows shown, a sitemap entry and an llms.txt line. The heading is `title` from the fact-verified ballot file, and `ballot_number` is shown only as a label. If the ballot file is missing, if `title` or `ballot_number` is absent, or if the title is a label such as "Ballot Number: 3", the build fails closed. The build also fails if any number lacks an adjacent source link, or if forecast or advocacy terms appear outside the quoted official text. Tests: `python3 tests/test_amend3.py`. CI (build-site workflow) runs it after `build.py`, then runs the tests; there is no deploy step. Merging to main is the publish step.

## Texas property tax rate pages (OM-SITE-TX-001)
`python3 statepages.py` (run after `build.py` and `amend3.py`) also writes the Texas hub at `/tx/property-tax-rates/` (canonical), the same hub at `/tx/` (its canonical points at the longer URL; it is not in the sitemap), and one page per county at `/tx/<slug of the CSV county field>/` (254 pages, e.g. `/tx/anderson-county/`), plus sitemap entries, an `llms.txt` line and the two YoY charts in `docs/charts/`.
Inputs are the eleven files under `data/tx/`, pinned in `data/SOURCES.lock` (hazeydata/openmillage@2166c845, calendar years 2021-2025). `tx_load` checks every file against the lock before anything is written; a sha256 mismatch, a missing lock entry or a missing file exits non-zero and writes nothing under `docs/tx/`. `tx_stats` also recomputes the county rose/fell/unchanged counts from the CSVs and fails if they disagree with the staged chart counts in `assets/charts/om-2026-11-06/tx-yoy-counts.json`.
Pages show `county` and `municipal` rows with `levy_component=total` only (school and special districts are in the data but not on these pages). Rates are the CSV `rate` string verbatim; an empty rate shows "not reported", an absent body "not listed", and Change is `n/a` unless both endpoints are non-empty. Every page carries the 2025 preliminary banner and the per-$100 (`statutory_per_100`) unit callout. Tests: `python3 tests/test_tx_statepages.py` (each check names the AC it covers).
The hub's data-files link (`TX_DATA_URL` in `statepages.py`, shown on `/tx/` and `/tx/property-tax-rates/`) is pinned to this public repo at the TX release merge commit, `https://github.com/hazeydata/openmillage-site/tree/76bec7d974bb92cbe4e0636368f94b8ce20ca91b/data/tx`, not `tree/main` (same pattern as the NC pin). It points at this repo rather than hazeydata/openmillage because the product repo is private and its URLs return 404 to visitors. Changing the pin means editing that constant and rebuilding the two hub pages.
