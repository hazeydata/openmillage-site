scanned PDF; phase 5 cell-level OCR reconciles 4 of 5 areas; area 7 (NFLMIP): the printed components sum to 13.4453 but the printed TOTAL is 21.2603 (the row prints no component that makes up the difference), so the file itself does not reconcile; county stays out
